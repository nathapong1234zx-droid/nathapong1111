โครงการตรวจสอบและทำความสะอาดชุดข้อมูลการขาย (Retail Sales Data: 10,000 รายการ) เพื่อแก้ไขปัญหาความไม่สมบูรณ์ ตรรกะทางธุรกิจที่ขัดแย้ง และความไม่คงที่ของราคา พร้อมสร้าง Web Dashboard สำหรับวิเคราะห์และสืบค้นข้อมูล

---

## 📌 สรุปผลการตรวจสอบและแก้ไขปัญหา 9 รายการ

### 🔴 กลุ่มที่ 1: ปัญหาความไม่สมบูรณ์และการกรองข้อมูล (4 ปัญหา)
1. **ปัญหาเพศไม่ตรงเงื่อนไข (197 รายการ):** กรองรายการที่มีค่า "ไม่ระบุ" ออกจากชุดข้อมูล คงเหลือเฉพาะเพศ "ชาย" และ "หญิง" (คงเหลือ 9,803 แถว)
2. **ปัญหาข้อมูลจังหวัดไม่ครบ 77 จังหวัด:** มีข้อมูลเพียง 25 จังหวัด โดยภาคตะวันตกไม่มีข้อมูล (0%) ได้จัดทำ Documentation ระบุขอบเขตการวิเคราะห์ (Scope Limitation) ป้องกัน Selection Bias
3. **ปัญหาชื่อจังหวัดไม่เป็นทางการ (264 รายการ):** ใช้ชื่อย่อ "อยุธยา" ทำการ Map เป็นชื่อทางการ "พระนครศรีอยุธยา" 100%
4. **ปัญหาข้อมูลคะแนนรีวิวสูญหาย (1,863 รายการ):** เป็น Missing Data (~19%) กำหนดให้คงสถานะค่าว่าง (Null) ไว้ ห้ามแทนที่ด้วย 0 เพื่อป้องกันคะแนนความพึงพอใจเฉลี่ย (CSAT) บิดเบือน

### 🟡 กลุ่มที่ 2: ปัญหาความขัดแย้งเชิงตรรกะทางธุรกิจ (4 ปัญหา)
5. **ปัญหาซื้อหน้าร้านแต่เก็บเงินปลายทาง (396 รายการ):** ซื้อหน้าร้าน (POS) แต่ลงวิธีจ่ายเงินเป็น เก็บเงินปลายทาง (COD) ได้ปรับเปลี่ยนวิธีชำระเงินเป็น "เงินสด"
6. **ปัญหาออร์เดอร์ยกเลิกแต่คิดค่าส่งและลงวันส่ง (456 รายการ):** สถานะ "ยกเลิก" ได้ปรับค่าจัดส่งเป็น 0 บาท, จำนวนวันจัดส่งเป็นค่าว่าง และคำนวณยอดรวมสุทธิใหม่
7. **ปัญหาผู้เยาว์ใช้บัตรเครดิต (234 รายการ):** ลูกค้าอายุ 15–17 ปี ชำระด้วยบัตรเครดิต ได้เพิ่มคอลัมน์ `หมายเหตุการชำระเงิน` ระบุเป็น `"บัตรเสริม/ผู้ปกครองยินยอม"` เพื่อการวิเคราะห์ด้าน Compliance
8. **ปัญหาอายุลูกค้าไม่เพิ่มขึ้นตามเวลา (4,379 รายการ):** ลูกค้าที่ซื้อซ้ำข้ามปี 2024–2025 อายุในระบบเท่าเดิม ได้คำนวณปรับอายุเพิ่มขึ้นตามปีที่สั่งซื้อจริง

### 🔵 กลุ่มที่ 3: ปัญหาความไม่คงที่ของราคาสินค้า (1 ปัญหา)
9. **ปัญหาราคาต่อหน่วยสินค้าชนิดเดียวกันมีหลายราคา (28 จาก 33 สินค้า):** คำนวณราคาฐานมาตรฐานมัธยฐาน (Median Base Price) ของแต่ละสินค้า และเพิ่มคอลัมน์ `ราคาฐานมาตรฐาน` และ `ส่วนต่างราคา` เพื่อการวิเคราะห์ Price Variance

## 🗂️ โครงสร้างไฟล์ในโครงการ

```text
├── index.html               # เว็บไซต์ Dashboard พร้อมกราฟวิเคราะห์และตารางสืบค้นข้อมูล
├── data.js                  # สถิติและชุดข้อมูลสำหรับแสดงผลบน Dashboard
├── dashboard_data.json      # ข้อมูลสรุปเชิงสถิติ (JSON format)
├── clean_data.ps1           # สคริปต์ PowerShell สำหรับทำความสะอาดข้อมูลอัตโนมัติ
├── validate.ps1            # สคริปต์ตรวจสอบความถูกต้องของข้อมูลหลัง Clean
├── sales_data.csv          # ข้อมูลตั้งต้น (Raw Data)
├── cleaned_sales_data.csv   # ข้อมูลหลังผ่านการทำความสะอาดแล้ว
└── README.md                # รายละเอียดโครงการ
```

## 🚀 การเรียกใช้งานสคริปต์

สามารถรันสคริปต์ทำความสะอาดข้อมูลได้ด้วย PowerShell:

```powershell
# ทำความสะอาดข้อมูล
powershell -ExecutionPolicy Bypass -File .\clean_data.ps1

# ตรวจสอบความถูกต้อง
powershell -ExecutionPolicy Bypass -File .\validate.ps1
```
