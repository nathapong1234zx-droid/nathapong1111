คะแนนรีวิวสูญหาย (Missing 19%)

🛡️ ป้องกัน: มี Incentive กระตุ้นให้รีวิวหลังรับพัสดุ

มาตรการป้องกันระยะยาว (Data Governance & System Prevention)

สถาปัตยกรรมการป้องกันปัญหาคุณภาพข้อมูลที่ระดับต้นทาง

เพื่อไม่ให้เกิดปัญหาเดิมซ้ำใน Data Warehouse และ BI Dashboard ควรติดตั้ง Database Constraints และ Application Validation ดังนี้:

Database Constraints

- ใช้ CHECK (status != 'ยกเลิก' OR shipping_fee = 0)
- ใช้ Foreign Key เชื่อมต่อกับ Master Province ID มาตรฐานกระทรวงมหาดไทย
- จัดเก็บ date_of_birth แทนฟิลด์ age คงที่

API & Business Rules

- ระบบ POS หน้าร้านต้องซ่อนปุ่มเลือก "เก็บเงินปลายทาง (COD)"
- มี Payment Gateway API Validation แยกประเภท Debit / Credit / Supplementary Card อัตโนมัติ
- ตรวจสอบความถูกต้องของเพศเป็น Mandatory Radio Button

Automated CI/CD Pipeline

- ติดตั้ง Data Contract & Great Expectations ใน ETL Pipeline
- Alerts อัตโนมัติเมื่อพบสินค้าชนิดเดิมแต่ราคาหลุดกรอบ Deviation (> 15% จาก Median)
- ประเมิน Missing Review Rate เป็นประจำทุกสัปดาห์
